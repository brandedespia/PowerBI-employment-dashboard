# PowerBI-employment-dashboard

![Dashboard Preview](dashboard_preview.png)

## Overview
An interactive Power BI dashboard analyzing graduate employment data across 4 educational levels from 2009-2025.

## Files
- `dashboard.pbix`: The main Power BI file.
- `Graduate_Employment_Situation.csv` The raw dataset.

## Data Source
The graduate employment situation data are from DATA.GOV.HK, available at: https://data.gov.hk/tc-data/dataset/hk-ugc-ugc-student-ges-statistics
